# Docker Manager

Supervisez et contrôlez vos conteneurs Docker depuis Home Assistant.

## Ce que vous obtenez

- 📊 **Monitoring complet** : CPU, RAM, réseau, état, santé de chaque conteneur
- 🎛 **Contrôle** : démarrer, arrêter, redémarrer en un clic
- 🔄 **Mises à jour** : détection automatique + mise à jour depuis le tableau de bord HA
- 🧹 **Prune** : nettoyage des images inutilisées via un service HA
- 🔒 **Sécurisé** : le conteneur Home Assistant est protégé contre l'arrêt accidentel

## Connexion

Fonctionne en local (socket Unix) ou à distance (TCP/TLS).  
Compatible HA OS via [docker-socket-proxy](https://github.com/Tecnativa/docker-socket-proxy).
